# Português em Movimento

Use pnpm. Run `pnpm verify` and `pnpm format:check` after code changes. Commit rebuilt `dist/` alongside source so plugin installs work without a build step.

Keep all learner data outside this repository. Never commit progress, lessons, conversations, credentials, host configuration or personal profiles. Tests must use temporary data directories. Keep the community default data directory separate from other editions.

Teaching uses `skills/portugues-em-movimento/SKILL.md` and its references. Adapt examples to configured learner settings. The Norwegian course manual is optional reference material; it does not set the learner's explanation language.
