# Start her

> Dette er den opprinnelige kursmanualen. I Codex brukes nå den aktive [kursinstruksen](../../skills/portugues-em-movimento/SKILL.md) og pluginens progresjonslogg. Den manuelle loggen nedenfor er en mal for bruk uten plugin.

`Português em Movimento` er et voice-first 12-ukerssystem for europeisk portugisisk.

## Før første økt

1. Les målet og voice-first-prinsippet i `00-KURSPLAN.md`.
2. Kopier `03-PROGRESJONSLOGG.md` til en privat mappe utenfor Git, og fyll ut profilen der.
3. Gi voice-chatten instruksen fra `01-VOICE-TUTOR-PROMPT.md`.
4. Start med dag 0 i `02-FØRSTE-14-DAGER.md`.
5. Lim inn øktloggen etter samtalen og oppdater frase- og feilbanken.

Fra dag 2 kan du bruke `04-DAGLIG-ØKTGENERATOR.md` til å generere neste økt fra siste progresjonsdata. Den første 14-dagersplanen styrer retningen; generatoren bestemmer nøyaktig innhold.

## Filene

- `00-KURSPLAN.md`: prinsipper, intensitet, 12 uker og måling.
- `01-VOICE-TUTOR-PROMPT.md`: fast adferd for AI-tutoren.
- `02-FØRSTE-14-DAGER.md`: detaljert oppstart og første kalibrering.
- `03-PROGRESJONSLOGG.md`: kanonisk hukommelse mellom voice-øktene.
- `04-DAGLIG-ØKTGENERATOR.md`: genererer dagens adaptive økt.

## Én regel

Feltmanualen skal støtte samtalen, ikke erstatte den. Dersom mer tid brukes på å organisere materialet enn på å lytte og snakke, er systemet ute av balanse.
